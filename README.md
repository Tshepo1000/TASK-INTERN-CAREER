# TASK-INTERN-CAREER

Java desktop applications built as practical tasks during an internship programme. Each project is a NetBeans/Swing application.

## Projects

| Folder | Description |
| --- | --- |
| `Calculator/` | A Swing GUI calculator |
| `School_portal/` | A Java school portal application |

## Getting started

Prerequisites: JDK 8 or newer and [Apache NetBeans](https://netbeans.apache.org/) (or any IDE that supports Ant-based Java projects).

```bash
git clone https://github.com/Tshepo1000/TASK-INTERN-CAREER.git
```

1. Open the project folder you want (`Calculator` or `School_portal`) in NetBeans.
2. Choose **Run Project** (F6).

## Tech stack

Java, Swing, Ant (NetBeans project format).

## Status

These are learning exercises. They run as standalone desktop apps and are not intended for production use.
